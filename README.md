# AnhPNM-TC-CIJS111-FINALTERM

Todo app built with ReactJS for the MindX Code Intensive final test.

## Features

- Switch between All, Active, and Completed tabs.
- Add new tasks from the All and Active tabs.
- Toggle a task between active and completed with the checkbox.
- Show completed tasks with a line-through style.
- Delete one completed task or delete all completed tasks from the Completed tab.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL printed in the terminal.

## Build

```bash
npm run build
```
